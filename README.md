# Квест подарков

Мобильный сайт-квест: 5 загадок, ответ на каждую — место в квартире, где спрятан подарок.

| № | Место |
|---|-------|
| 1 | Камин |
| 2 | Балкон |
| 3 | Прихожая |
| 4 | Духовка |
| 5 | Стиральная машина |

## Как изменить тексты
Все загадки, подсказки и принимаемые варианты ответа лежат в начале файла `quest.js` (массив `RIDDLES`).
Ответ засчитывается, если в нём есть любая строка из `keys` (регистр и «ё» не важны).

За загадки 1–4 выдаётся по цифре кода, код открывает 5-ю загадку. Сам код задаётся константой `CODE` в `quest.js` (4 цифры).

Прогресс сохраняется в браузере. Сбросить его можно кнопкой «Начать заново» на первом экране или «Пройти заново» в финале.

## Публикация на GitHub Pages
1. Залить файлы в корень репозитория (ветка `main`).
2. Settings → Pages → Source: **Deploy from a branch**, Branch: `main` / `(root)`.
3. Через минуту сайт будет доступен по адресу `https://<user>.github.io/<repo>/`.
